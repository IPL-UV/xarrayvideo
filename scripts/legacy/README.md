Legacy helpers kept for reproducibility but not part of the active benchmark or packaging workflows.

- `check_max_vals.py`: inspect dataset value ranges used during review and calibration.
- `find_processing_gap.py`: ad hoc scan for missing batches in older processed outputs.
- `measure_ram.py`: subprocess-based RAM measurement experiments.
- `plot_synthetic.py`: plotting helper for the synthetic missing-data experiments.
- `deepextremecubes_to_tacov2.py`: one-time DeepExtremeCubes TACO v1 to v2 migration.
- `dynamicearthnet_to_tacov2.py`: one-time DynamicEarthNet TACO v1 to v2 migration.
